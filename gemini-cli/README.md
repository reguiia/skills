# Gemini Studio

Welcome to Gemini Studio! This is a user-friendly tool that helps you create and work with documents using natural, conversational prompts.

## Getting Started

To get started, you will need to install the necessary dependencies.

### Installation

Please follow the installation instructions from the previous `README.md` file. The required system and Python dependencies are the same.

## How to Use Gemini Studio

To start the tool, run the following command in your terminal:

```bash
python3 gemini-studio.py
```

The tool will then guide you through the available options.

### Creating a Presentation

To create a new presentation, simply choose the "Create a new presentation" option from the main menu. The tool will then ask you for a title for your presentation and guide you through creating each slide.

When you're finished, the tool will automatically generate a `.pptx` file for you.

## Advanced Tools

For more advanced users, the individual CLI tools are still available:

- `gemini-pptx.py`
- `gemini-docx.py`
- `gemini-xlsx.py`
- `gemini-pdf.py`

You can get more information about each tool by running it with the `--help` flag:

```bash
python3 gemini_pptx.py --help
```
